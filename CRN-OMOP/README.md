# CRN-OMOP

Cancer Registry of Norway OMOP Common Data Model (CRN-OMOP).

This directory contains mapping specifications, documentation, and release information for the Cancer Registry of Norway OMOP implementation.

## Current Release

**2025.1**

Release 2025.1 represents the current recommended version of the CRN-OMOP mapping specifications.

## Scope

CRN-OMOP is the OMOP Common Data Model implementation maintained by the Cancer Registry of Norway.

The mapping specifications contained in this repository are used to transform Cancer Registry of Norway data into the OMOP Common Data Model.

## Mapping Specifications

Mapping specifications are organized by OMOP domain.

Current domains include:

- Condition Occurrence
- Drug Exposure
- Procedure Occurrence
- Measurement
- Observation
